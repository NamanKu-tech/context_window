THE PROBLEM

Most chatbots know the facts.
They do not know the room.

01

Shared spaces change risk

A Slack answer is visible to everyone in a channel—not just the person asking. Source permissions alone do not prevent an assistant from repeating protected context elsewhere.

02

Truth is not enough

A fact may be correct and technically accessible, yet still be inappropriate to repeat because it is confidential, time-sensitive, or meant to stay within a team.

03

Safety must precede generation

Prompt instructions are not a security boundary. Need to Know removes audience-incompatible facts before they ever become model context.

ARCHITECTURE

Policy before language.

The model never decides who is allowed to see a retrieved fact. Deterministic audience checks run first; contextual reasoning only sees candidates that already passed.

01

Hard gate

deterministic
venue.audience ⊆ source.audience

If even one person in the current venue could not see the source, the fact is held before any model call.

02

Soft gate

structured AI decision
confidentiality · purpose · timing

Even technically visible facts can be held if context says “don’t spread”, “keep this here”, or similar.
